YAVIS – Mining-Modul integriert

1. Entpacke den gesamten Projektordner.
2. Installiere Python 3.11+ und Abhängigkeiten: python -m pip install -r requirements.txt
3. Starte YAVIS mit: python main.py
4. Öffne links die Kategorie „Mining“.
5. Prüfe Strompreis, GPU-Leistung und Ertragsschätzung. Die Ertragsschätzung ist kein Live-Wert.
6. GPU-Telemetrie muss verfügbar sein (NVIDIA-Treiber mit nvidia-smi). Wenn sie fehlt, blockiert YAVIS den Miner-Start.
7. Für echten Mining-Start muss eine vertrauenswürdige Miner-.exe separat installiert und ausgewählt werden. YAVIS lädt keine Mining-Software herunter.
8. Pool-/Algorithmus-/Worker-Argumente sind vom ausgewählten Miner und Pool abhängig. Niemals Seed-Phrase oder privaten Schlüssel eingeben.

Sicherheitsverhalten:
- explizite Bestätigung vor Start
- keine Shell-Ausführung
- Stopp bei 87 °C, Warnung ab 83 °C
- Prozess wird beim Beenden der App gestoppt
- Logdatei liegt im YAVIS-Benutzerdatenordner als mining.log
